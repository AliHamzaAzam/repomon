# Repomon — junction exploration

Six new vector concepts developed from the user's preference for three independent agent/repo lanes feeding one mission-control hub. This round varies the connection structure, not only the stroke weight or endpoint style.

1. Ports: independent lanes dock separately into one circular control hub.
2. Manifold: channels are cut into one solid rounded body, retaining a distinct silhouette without color.
3. Handoff: staggered branch arrival positions give the three-lane structure an asymmetric rhythm.
4. Uplink: the preferred lane architecture is turned upright.
5. Switch: diagonal routes create directional emphasis.
6. Harbor: a protective outer boundary contains the lane junction.

Recommended shortlist: 01 Ports and 03 Handoff. All six are concepts awaiting selection; final logo, Apple Liquid Glass icon and Windows icon production remain pending.

Files: `overview.png` and `overview.svg` show the set; `review-board.html` shows larger studies; numbered `.svg` and `-mono.svg` files are editable transparent symbol masters. `build.py` reproduces them with precise vector shapes and rsvg-convert. The study wordmark remains provisional system typography.

Generated directly as SVG, without ImageGen. Existing app icons have not been replaced.
