# Repomon geometric logo concepts

Five original vector designs built directly from circles, rectangles, circular arcs, and straight cuts. No image-generation tool was used for this round.

- `overview.png` / `overview.svg`: all five marks and their construction geometry.
- `01-switchyard.svg` through `05-pair.svg`: transparent editable symbol masters.
- `*-study.svg` / `*-study.png`: each mark beside its construction diagram and a provisional wordmark.
- `review-board.html`: local comparison view.
- `build.py`: reproducible geometry and raster export using rsvg-convert.

The construction diagrams derive from the actual shapes used in the corresponding symbols. Masks preserve editable subtractions and transparent counters. Wordmarks on study boards use Helvetica Neue with Arial/sans-serif fallback; type selection and outline conversion will follow selection of a symbol.

Recommended shortlist: Lookout for a recognizable mascot and Switchyard for a direct monogram. Workspaces most literally expresses multiple repositories. Colors remain adjustable.

Awaiting the user's selected direction before refinement, final lockups, Apple Icon Composer / macOS icon production, and Windows ICO exports. No application assets have been replaced.
