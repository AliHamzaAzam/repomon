## macOS 27 Liquid Glass

`macos/Repomon.icon` is an editable native Icon Composer bundle. The two foreground layers are
unmasked 1024px canvases containing the source shape. The native renderer adds the glass
finish, refraction, highlights, and system mask. The orange center is a separate foreground group.
The dark appearance lightens only the graphite fill to retain contrast; geometry is unchanged.
Default, dark, clear light/dark, and tinted light/dark previews are actual native exports.

Compiled files in `macos/compiled/` include `Assets.car` and `Repomon.icns`. The latter is the
static fallback generated by Apple's compiler; the catalog carries the native layered icon.
Tools used: Apple Icon Composer 2.0 (109.4), Xcode 27 actool. No ImageGen or raster tracing was used.

### Compatibility with macOS 26 and earlier

The original export passed live open SVG strokes to Icon Composer. With a layer fill override,
the macOS 26 preview filled across those open path interiors and covered the negative spaces.
`tools/outline-strokes.swift` now expands the strokes with Core Graphics and normalizes the filled
contours. The mesh layer contains only closed, filled shapes, so recoloring does not close the
original centerlines. The editable source SVG and Windows/in-app artwork are unchanged.

The native catalog and legacy ICNS are rebuilt with deployment target 11.0.
`macos/repomon-macos-legacy-256.png` is extracted from that ICNS, not a separate mockup.
The build checks that all export contours are closed. Raster comparison at 1024px verifies the
same bounds and limits changes to antialiasing at edges. Six native appearance exports and the
legacy fallback were inspected. Direct rendering with the 26 engine requires Icon Composer's
26 preview control; the installed export CLI exposes no system-version selector.

The design follows Apple's [current app-icon guidance](https://developer.apple.com/design/human-interface-guidelines/app-icons),
updated June 8, 2026: simple centered content, square unmasked layers, system-supplied visual effects,
and recognizable appearance variants.

## Windows

`windows/repomon.ico` contains ten 32-bit RGBA sizes from 16 through 256px. PNG exports extend to
1024px. `windows/repomon-windows.svg` is the editable flat tile composition. The selected mark is
uniformly scaled as a whole without editing its paths. See `windows/README.md` for sizing details.

## Rebuild and integration

Run the commands in `docs/desktop.md`. The app's BrandMark uses the exact geometry with existing
theme colors. The favicon keeps the source colors and is pixel-identical to the master when rendered
at the same size. Platform assets have been installed in the existing Tauri packaging paths.

The saved `macos/Repomon.icon` document is authoritative for glass styling. `build-macos.py`
compiles it without changing any source bundle file, so manual transparency and lighting edits
survive future builds. Geometry regeneration is a separate explicit `export-macos-layers.py` step.
`install-macos.py --app /Applications/Repomon.app` also updates the installed icon resources with
backups and an executable-hash check; it does not restart the app.

Native build, geometry equality, PNG and ICO dimensions, catalog inspection, existing brand tests,
and TypeScript checks are used for validation. Installed applications use compiled resources,
so saved Composer edits take effect after compilation and installation.
