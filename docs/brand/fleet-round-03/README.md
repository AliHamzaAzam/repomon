# Repomon — fleet identity concepts

This round responds to the user's correction that the logo must express Repomon's actual purpose: mission control for multiple AI coding agents across repositories and worktrees.

## Design language

Independent modules represent agents, sessions, or repo workspaces. Connections and enclosure represent coordination. A contrasting orange node represents shared control or an attention signal, depending on the concept. All concepts have one-color versions so the mark does not rely on its palette.

1. **Conductor**: separate lanes converge at one control point. Recommended for communicating Repomon's primary value.
2. **Fleet R**: the name's initial combines a connected bowl and branch with a three-part lane spine.
3. **Mission**: terminal sessions in one boundary, with a detached attention indicator. Best emphasis on monitoring and triage.
4. **Repo Grid**: independent workspace corners surround a shared core.
5. **Overwatch**: a lens contains multiple agents and emphasizes one requiring attention.

## Files

- `overview.png` / `overview.svg`: comparison with semantic captions and one-color checks.
- `01-conductor.svg` through `05-overwatch.svg`: transparent vector symbol masters.
- `*-mono.svg`: single-color masters.
- `*-study.svg` / `*-study.png`: clean symbol and construction view, with provisional wordmark.
- `review-board.html`: local comparison gallery.
- `build.py`: editable geometry and reproducible SVG/PNG exports using rsvg-convert.

Direct vector construction, without ImageGen. Circle centers, curves, rectangles and masks are preserved in the source. The study wordmarks use Helvetica Neue with Arial/sans-serif fallback; final typography and conversion to outlines follow symbol selection.

The selected direction still needs the user's approval before final logo refinement and macOS Liquid Glass / Windows icon production. Existing application icons remain in place.
