# Repomon — abstract core identities

Responds to the user's request for more creative, abstract forms after selecting a centered orange hub. This round uses a shared center as a compositional anchor rather than illustrating agent connections literally.

- Drift: paired circular crescents enclose a centered lens.
- Counterweight: two opposed rounded masses balance around a central disc.
- Phase: parallel diagonal gaps divide one circular field around a focal center.
- Duet: two rounded folds surround a shared square.
- Facet: separated hexagonal bands enclose a rotated central square.
- Resonance: broad opposing waves surround a central capsule.

All marks are original editable SVG constructions. The two-color palette and centered orange anchor are consistent; monochrome versions assess silhouette without the accent. Study wordmarks remain provisional Helvetica Neue with Arial/sans-serif fallback.

`overview.png` / `overview.svg` show the six marks. `review-board.html` offers larger studies. Numbered SVG files are transparent symbol masters; `-mono.svg` files are monochrome versions. `build.py` reproduces the geometry and PNG exports through rsvg-convert.

These remain exploration candidates. Final wordmark refinement and macOS Liquid Glass / Windows icon production await the user's selection. Existing application assets are unchanged.
